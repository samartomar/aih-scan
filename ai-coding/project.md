# Repository contract

`aih-scan` is a private, publication-deferred TypeScript/Node.js bootstrap for
a future scanner runtime. This bootstrap deliberately contains no scanner CLI,
Cisco integration, product protocol, remote, registry, or publication setup.

## Commands

- `npm run typecheck`
- `npm test`
- `npm run lint`
- `npm run build`
- `npm run repo:init`
- `npm run repo:doctor`

The repository uses npm, ESM, TypeScript, Vitest, and Biome. The committed canon
is manual; never run an installed aih-scan against this checkout.
